# PetFlow

Este repositório contém a documentação e os arquivos principais referentes ao Trabalho de Conclusão de Curso da **Equipe 18**.

## 📁 Estrutura do Projeto

Os arquivos foram organizados na pasta `Documentação/` para facilitar a navegação:

* **[Documentação/](Documentação/)**
    * `Documento.docx`: Documentação do projeto.
    * `Plano de testes_Sprint 4_ Equipe_18.xlsx`: Detalhamento dos testes realizados durante a Sprint 4.
    * `Proposta-Técnica-Equipe-18.docx`: Documento contendo a proposta técnica inicial.
    * `Projeto - Vídeo - Apresentação.url`: Atalho para o vídeo de apresentação do projeto.
    * `Protótipo - FIGMA.url`: Atalho para visualização do protótipo de alta fidelidade no Figma.

## 🚀 Como Visualizar

1.  **Documentos e Planilhas:** Podem ser baixados diretamente da pasta `Documentação`.
2.  **Links Externos:** Para acessar o protótipo ou o vídeo, basta abrir os arquivos `.url` ou clicar nos links abaixo:
    * [Acessar Protótipo no Figma]((https://www.figma.com/proto/jHI7lCW2uwNwfTQX7WLjL3/Petflow---Protótipo?node-id=32-134&t=lS5YAjYoytcffQ9n-1&starting-point-node-id=32%3A134))
